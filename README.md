# mystuperformance

This study applies supervised machine learning techniques to predict secondary school students’ end-of-year mathematics performance using socio-economic, demographic, and academic history data. Data were obtained from the UCI Machine Learning Repository’s Student Performance dataset. A logistic regression model was developed to classify students as either pass or fail. The dataset was preprocessed through cleaning, encoding, feature scaling, and transformation of the final grade into a binary outcome variable. The model was trained using an 80/20 train-test split. The objective of this project is to provide an early-warning system that identifies students at risk of academic underperformance and supports data-driven intervention strategies. Results demonstrate the potential of predictive analytics in educational decision-making.
